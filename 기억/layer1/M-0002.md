## 맥락

Graphify 0.9.48 명령은 전역에 설치되어 있었지만 프로젝트 스킬은 비어 있었다. 사용자는 Cataclysm-DDA를 대상으로 `.claude`와 `.agents`가 함께 쓰는 설정을 요청했다.

스킬 정본은 `.claude/skills/graphify/`에 둔다. `.agents/skills/graphify/`는 기존 미러 생성기가 만든다. Codex의 PowerShell 명령과 서브에이전트 도구 차이는 `.agents/diff/graphify/` 오버레이에 둔다.

루트 `.graphifyignore`는 Graphify 입력을 `cataclysm-dda/`에 한정한다. 그래프 출력은 루트 `graphify-out/`에 두고 Git에서 제외한다. 이 구조는 두 런타임이 같은 기본 경로로 그래프를 조회하게 한다.

## 검증 결과

코드와 JSON을 로컬 AST로 추출했다. SQL 파일 4개를 포함하기 위해 `tree-sitter-sql` 0.3.11을 추가했다. 최종 그래프에는 노드 70,528개, 연결 170,052개, 커뮤니티 1,943개가 있다.

`graphify query`와 `graphify path`가 실제 Cataclysm-DDA 경로를 반환했다. 미러 검사, 두 스킬 유효성 검사, Claude 훅 출력, 설정 구문 검사도 통과했다. 다중 연결 진단은 누락 연결, 고아 연결, 중복 연결 붕괴를 찾지 않았다.

## 알려진 한계

그래프에는 자체 참조 2개가 있다. 하나는 `item_info`의 일반 인자 참조다. 다른 하나는 Visual Studio 솔루션 노드 ID 충돌에서 생긴 `contains` 자체 참조다.

Graphify는 `cataclysm-dda/tools/graphs/damage.r`을 지원하지 않는다. 문법 오류가 있는 파일 80개는 일부 기호만 추출됐다. `cataclysm-dda/data/mods/Magiclysm/items/enchanted_tokens.json`은 민감 파일명으로 오인되어 제외됐다.
