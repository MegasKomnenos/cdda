## 맥락

활성 `parallel-turn-impl` DAG는 삭제된 전체 테스트 스크립트와 전체 실행 일원화 결정을 사용하고 있었다. 새 하네스는 정확한 테스트 이름, 논리 조각, 빌드 기록, 재개 가능한 결과를 요구하므로 미착수 행의 테스트 생산·소비 계약을 다시 써야 했다.

완결 행과 과거 예외 기록은 역사 기록으로 보존했다. 새 사용자확정 결정과 후속 불변식이 행 2.19.6부터 행 z까지의 현행 계약을 덮는다.

## 테스트 책임

행 2.19.6은 `proficiency_gain_short_crafts`, `crafting_skill_gain`, `monster_speed_description` 세 테스트를 두 논리 조각으로 실행한다. 행 2.6부터 2.13까지의 작업자는 수정 범위를 확정한 뒤 정확한 표적 테스트 이름과 논리 조각을 자기 자식 행에 기록한다.

행 2.14는 최종 빌드, 데이터 검증, 전체 일반 테스트, 기능 인수, 성능 인수를 소유한다. 전체 일반 테스트 명세는 빌드 기록의 `hidden: false` 이름 1,919개를 빌드 기록 순서로 64개씩 나눈다. 현재 빌드 기록에서 30개 조각이 만들어지고 마지막 조각은 63개 테스트를 가진다.

행 2.15, 검증런, 노드 싱크, 행 2.z, 행 3, 행 z는 빌드 기록, 데이터 검증 기록, 정규화 명세, `result.json`, 프로파일 증거를 판정한다. 같은 전체 테스트를 반복하지 않는다.

## 예산과 정본 투영

행 2.6부터 2.15까지가 게이트 2 결정 전문을 읽으면 모델 예산을 넘었다. `행/2.d/작업DAG-결정축자.md`는 원본의 결정 절부터 끝까지를 축자로 투영한다. 소비자는 원본 SHA-256을 투영 frontmatter와 대조한다. 커밋 전 대조에서 SHA-256과 15행 축자가 모두 일치했다.

소급 검증런 하나도 행 2 완료보고를 포함하면 `sonnet` 200,000토큰 예산을 넘었다. 검증을 행 2.20, 2.22, 2.21로 분할했다. 세 행의 소요 견적은 각각 약 195,128토큰, 195,818토큰, 189,362토큰이다.

## 검증 상태

`dag_check.py`는 운전 모드에서 무발견과 exit 0을 냈다. 활성 파견문 18개의 읽기 목록과 budget `--files` 집합은 전건 일치했다. `git diff --check`도 통과했다.

정식 verify-rounds의 기본 `mixed` 배정은 현재 런타임에 없는 Claude 모델을 요구했고, 런은 커밋된 깨끗한 산출물 기준선도 요구했다. 독립 Codex 검토 세 기가 하네스 정합성, DAG 운전성, 문면 완전성을 대신 반증했다. 검토가 찾은 명세 정규화, 재개 처분, 예산 누락, 검증런 분할 결함을 수리한 뒤 재검증을 통과했다.
