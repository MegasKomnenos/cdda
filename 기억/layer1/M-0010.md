## 맥락

기존 `test-game.ps1`은 빌드, 전체 테스트, 데이터 consistency를 한 실행에 묶었다. 호출자는 일부 테스트만 필요해도 전체 실행을 기다려야 했다. 프로세스가 충돌하거나 정지하면 완료한 테스트와 미완료 테스트를 구별할 결과 파일도 없었다.

새 하네스는 빌드, 데이터 검증, 테스트 실행을 `build-tests.ps1`, `verify-test-data.ps1`, `run-tests.ps1`로 분리한다. 빌드 기록은 서브모듈 HEAD, 소스 지문, 실행 파일 SHA-256, 일반·숨김 테스트 이름 전건을 고정한다. 테스트 실행은 정확한 테스트 이름과 숫자 seed를 가진 논리 조각을 받는다.

CDDA 서브모듈 커밋 `3092abfcfcbd30c9d97bd12cafda07daab54178c`은 한 프로세스에서 여러 논리 조각을 순서대로 실행한다. 테스트 진행 이벤트는 JSONL에 남고, 테스트가 만든 파일은 시도별 출력 디렉터리에 격리된다.

## 실행 계약

테스트 통과와 테스트 실패는 모두 완료 결과다. 프로세스 충돌, 예기치 않은 종료, 진행 정지는 프로세스 실패다. 제어기는 프로세스 실패에서 완료 조각을 보존하고 미완료 조각만 다시 실행한다.

일반 테스트 실행은 데이터 consistency를 생략한다. `verify-test-data.ps1`이 consistency를 별도 실행하고 `verification.json`을 빌드 ID, 실행 파일 SHA-256, 소스 지문에 묶는다.

## 검증 상태

새 서브모듈 HEAD에 묶인 빌드 기록은 `build/test-builds/20260828T025709534Z-9992af2a88db/build.json`이다. 하네스 자체 테스트는 프로세스 충돌 재시도, 완료 조각 재개 건너뛰기, 다중 조각 단일 프로세스 실행, 테스트 실패 뒤 후속 조각 실행, 출력 격리, 해시 불일치 거부를 통과했다.

전체 데이터 검증은 이 커밋에서 반복하지 않았다. 전체 consistency는 약 45분이 걸리며 활성 DAG의 최종 인수 행이 실행 책임을 가진다.

## 남은 위험

`build-tests.ps1`의 `Get-TestNames`는 테스트 이름 열거 실행의 종료 코드를 검사하지 않는다. 현재 빌드 기록은 1,919개 일반 테스트와 71개 숨김 테스트를 정상 열거했다. 열거 실행이 실패하면서 출력 일부를 남기는 경우에는 잘못된 빌드 기록이 만들어질 수 있다.
