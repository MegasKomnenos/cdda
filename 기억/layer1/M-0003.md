## 맥락

루트 저장소에 Windows 빌드 도구 설치, 게임 빌드·배포, 전체 단위 테스트 스크립트가 추가됐다. `build/`는 컴파일 산출물과 로컬 저장 파일을 담으므로 루트 Git 추적에서 제외했다.

`cataclysm-dda` 서브모듈은 Windows 턴 CPU 프로파일러를 추가한 별도 커밋으로 전진했다. 루트 스크립트와 서브모듈 포인터를 같은 커밋에 담아 빌드 절차와 소스 기준을 맞춘다.

## 검증 상태

PowerShell 파서가 루트 스크립트 세 개와 프로파일 실행 스크립트의 문법을 통과시켰다. 프로파일러 활성 빌드가 MSVC 컴파일과 링크를 통과했다. 격리된 임시 세계에서 10턴을 기록했고 JSON과 HTML 보고서를 생성했다.
