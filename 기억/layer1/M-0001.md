## 맥락

`C:\cdda`에는 에이전트 설정과 작업 기억이 있었지만 Git 저장소는 없었다. `cataclysm-dda`는 공식 `cleverraven/cataclysm-dda` 원격을 추적하는 독립 Git 저장소였다.

루트 저장소는 `main` 브랜치로 초기화했다. `cataclysm-dda`의 전체 이력을 루트 커밋에 복제하지 않고, 현재 공식 커밋을 가리키는 Git 서브모듈로 등록했다. GitHub 원격은 계정 `MegasKomnenos`의 비공개 `cdda` 저장소로 만든다.

## 검증 상태

비밀값 패턴과 대용량 파일을 검사했으며 게시를 막는 항목은 없었다. 스킬 미러 검사는 157개 파일에 드리프트가 없음을 확인했다.

직접 실행한 `do-dag` 테스트는 `.agents/hooks.json` 부재 때문에 두 항목에서 실패했다. 사용자는 훅 누락 조사와 수리를 건너뛰도록 지시했다. 첫 커밋은 이 기존 누락을 유지한다.
