# 병렬 턴 구현 프레임과 체급

## 브리핑

현재 `game::do_turn()`은 `cataclysm-dda/src/do_turn.cpp:606-908`에서 13개 대상 측정 요소를 단일 가변 게임 상태에 순차 적용한다. 입력 상태, 변경 레코드 병합기, 결정론 난수 스트림, 지속 작업자, 작업자 수 명령줄, 병렬 전용 시험은 없다. 현재 Windows 프로파일러와 기준 프로파일 원자료는 있으나, 프로파일 schema 1은 작업자와 병합 CPU를 구분하지 않는다. 근거와 차분 전건은 `C:\cdda\.sdd\dag\parallel-turn-impl\기준선.md`다.

체급은 전면을 유지한다. 구현은 공유 상태의 다중 쓰기를 값으로 전환하고, 스레드 실행 순서와 작업자 수에서 독립인 결과를 보장하며, 턴의 상태 전이·오디오 소유·종료 합류·프로파일 표면을 함께 바꾼다. 전면보다 낮은 체급으로 변경할 실물 근거는 없다.

승인할 구현 프레임을 하나 선택한다.

1. **전면·단계 구현 (권고)**: 인계문 16.2~16.9절을 순서대로 실행한다. 먼저 프로파일러와 공통 직렬 구조를 만들고, 지속 작업자와 결정성 시험을 닫은 뒤 지도·플레이어·음향·생물 그룹을 이관하고, 마지막에 새 턴 순서와 성능 게이트를 결선한다. 13개 측정 요소와 7절의 직렬 유지 범위는 바꾸지 않는다.
2. **기반만 구현**: 인계문 16.2~16.4절만 구현한다. 13개 계산 그룹의 이관과 최종 성능 게이트는 후속 국면으로 이월한다. 이는 인계문의 첫 완료 범위를 나누므로 사용자 변경이 필요하다.
3. **재기안**: 인계문 3절의 사용자 승인 규칙 또는 6~7절의 범위를 다시 연다. 구현 DAG를 폐기하고 새 정본을 작성한다.
