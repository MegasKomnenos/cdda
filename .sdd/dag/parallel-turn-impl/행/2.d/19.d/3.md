## 임무

### 목적 진술 재료

성공한 기준 실행만 구현 노드 2.6을 열 수 있는지 검증한다. 원자료가 요구하지만 산출물에 구현되지 않은 내용도 검사한다. 산출물 밖 파일 자체의 문제는 검사하지 않는다.

### 불변식 재료

- 두 상태 파일은 네 명령과 각 stdout을 구분한다.
- 두 시작 커밋은 각 `rev-parse HEAD` stdout과 같은 40자리 소문자 16진 값이다.
- 전체 테스트 성공이 기준 프로파일보다 앞선다.
- 기준 프로파일은 10,000턴과 seed `cdda-turn-profile-v1`을 기록한다.
- 실행 파일 SHA-256은 JSON 실물과 보고에서 같다.
- 루트와 서브모듈의 시작·종료 측정값과 비교 결과는 보고에서 독립적으로 다시 판정한다.
- 시작 시점의 기존 tracked 변경은 HEAD, unstaged binary diff, staged binary diff SHA-256을 종료 측정과 각각 대조한다.
- 시작 시점의 기존 untracked 파일은 상대 경로, 파일 유형, 내용 SHA-256을 종료 측정과 각각 대조한다.
- `기준출력선재`와 `기존테스트실패`는 성공으로 바뀌지 않는다.
