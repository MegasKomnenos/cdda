# 증거 부록

## 1. 편집 전 RED

`행/2.d/19.md`와 `행/2-보고.md`에서 `rev-parse HEAD`, `시작 커밋`, `40자리 소문자 16진`, `커밋.*(검사|형식)`, `git status --short --branch`를 검색했다. 두 `rev-parse HEAD` 명령, 두 시작 커밋 기록, 두 형식 검사는 검색 결과에 없었다. 따라서 상태 출력만으로 V-01을 충족할 수 있는 RED를 확인했다.

## 2. 편집 뒤 의미 검색

`행/2.d/19.md`에서 네 Git 명령은 전개 지시 4단계의 순서 있는 코드 블록에 있다. CK-1과 CK-2는 두 증거 파일의 명령·stdout 분리 기록과 각 시작 커밋의 40자리 소문자 16진 형식·stdout 동일성 검사를 요구한다. CK-8과 전개 지시 8단계는 상태만 있거나 시작 커밋 기록 하나가 없으면 2.19 작업자와 2.19.z가 완료하지 못하게 한다. `행/2-보고.md`의 V-01과 BL-09는 두 상태 증거 파일의 네 Git 명령·stdout, 시작 커밋 기록, 형식·동일성 검사를 지목한다.
