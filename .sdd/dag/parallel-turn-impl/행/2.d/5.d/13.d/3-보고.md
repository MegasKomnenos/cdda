# 직접 자식 병행 자격 전건 수리 보고

행 2의 직접 자식 실행 행은 2.1부터 2.19까지 19개다. 게이트와 싱크는 실행 행이 아니므로 모집단에서 제외했다. `행/2-보고.md`의 병행 자격 판정 표는 기존 120행을 보존하고 2.16·2.17·2.18 관련 51행을 추가했다. 표 행 수는 171행이다.

## 2.16·2.17·2.18의 닫힌 쓰기 집합

| 행 | 파견문의 겨냥이 닫은 쓰기 집합 |
|---|---|
| 2.16 | `행/2.d/16.d/`, `행/2.d/16-보고.md`, `파견표.md` |
| 2.17 | `행/2.d/` 전체 경계, `파견표.md` |
| 2.18 | `행/2.d/18.d/`, `행/2.d/18-보고.md`, `파견표.md`, `이음새.md` |

2.17의 `행/2.d/` 전체 경계는 2.1~2.19의 행 파일·보고·하위 디렉터리를 포함한다. 따라서 2.17과 다른 직접 자식 행 사이의 쓰기 교집합은 디렉터리 경계로 기록했다. 2.16과 2.18은 `파견표.md`를 조건부로 쓴다. 2.18은 `이음새.md`도 쓴다.

## 판정 근거와 실제 수렴

2.16은 2.2의 판정 파일을 읽는다. 2.17은 2.1의 판정 파일을 읽는다. 2.18은 2.3의 판정 파일을 읽는다. 세 소비 간선은 병행 자격 표에 순차 사유로 기록했다.

2.5는 현재 파견표에서 2.16.z, 2.17.z, 2.18.z를 선행으로 받는다. 이 선행은 수리 전개가 완료된 뒤의 실제 수렴이다. 2.1~2.4와 수리 전개 사이에서 최초 설계에 소비 간선과 쓰기 교집합이 없던 쌍은 병행으로 기록했다. 이 보고와 `행/2-보고.md`는 완결 행의 과거 선행과 상태를 바꾸지 않았다.
