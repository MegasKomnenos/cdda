## 메인 결정 (사용자 축자 아님)

- 종결 방식: 오케를 다시 쏘지 않고 메인이 대응표 6항의 조기 종결을 직접 한다. 마커를 `close --phase parallel-turn-impl`로 닫고 `sweep`으로 잔존 브랜치를 회수한다. 미착수 22행은 파견표에 `미착수`로 남긴다. 병렬 턴 구현은 이 국면에서 완성되지 않았다.
- 실행 로그: Codex 행의 stderr 실행 로그(`*로그*.txt`)는 사용자 지시로 저장소에서 추적하지 않는다. 이관 뒤에도 루트 `.gitignore`가 막고, 이미 추적되던 132개는 추적에서 뺀다. 이관 절차의 「앞에 있고 뒤에 없는 것을 `git add -f`로 되살린다」를 이 132개에는 적용하지 않는다.
- 로컬 제외: `.git/info/exclude`가 행 2.19.17의 완료 신호 `행/2.d/19.d/17-보고.md`를 숨기고 있었다. 그 행의 완료 기준(R-05 Git 상태 보존)을 맞추려고 넣은 줄로 보이고, 보고는 정상 기록이므로 제외 줄을 지우고 함께 이관한다.
- 인계문 검증본: 이 국면의 기준선이 입력으로 삼은 `임시/cdda-parallel-turn-implementation-handoff_검증_2026-08-24/`와 행 2.19.7의 궤적도 `임시/2.19.7-프로세스-궤적.mmd`를 이관 디렉토리로 옮기고 `임시/`를 비운다. 옮긴 좌표는 각각 `dag/parallel-turn-impl/cdda-parallel-turn-implementation-handoff_검증_2026-08-24/`와 `dag/parallel-turn-impl/행/2.19.7-프로세스-궤적.mmd`다. 기록 안의 `임시/` 좌표는 고치지 않는다 — 이관은 실물을 보존하지 좌표를 보존하지 않는다.
