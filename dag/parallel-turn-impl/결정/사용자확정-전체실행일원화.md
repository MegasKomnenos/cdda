## 브리핑

2.19 사슬의 남은 행 중 2.19.5(R-03)와 2.19.2(B-03)가 각자 전체 테스트 스위트 실행(`test-game.ps1`, 약 1시간)을 요구했고, 2.19.3(검증런)·2.19.8·2.19.8.z(기각 보관 재판정)가 그 뒤에 있었다. 메인이 "전체 스위트 실행을 사슬 끝 한 번으로 몰기"를 제안했고, 사용자가 그보다 넓은 축소를 지시했다.

## 결정 (메인 기입 — 사용자 응답과 확정 문면)

응답 방식: 직접 규범을 담은 자유 입력

사용자 응답: 「전체 실행은 2.19.6에서 한 번 하고 끝나면 그걸로 그냥 끝내. 2.19.3도 그냥 버리고, 2.19.8 + 8.z도 버리고, 2.19.5는 정확히 뭘 하는거야. 2.19.2도 전체 테스트 돌리는거 없이 그냥 10,000턴 프로파일 + 실행 파일 해시만 생성하게 하고 싶은데」

확정 문면: 전체 테스트 스위트 실행은 행 2.19.6의 1회로 끝낸다. 그 exit 0 증거(`행/2.d/19.d/6-보고.md`)가 이 국면의 전체 테스트 잣대를 진다. 행 2.19.3, 2.19.8, 2.19.8.z를 파견표에서 제거한다. 행 2.19.2는 전체 테스트 없이 10,000턴 기준 프로파일과 실행 파일 해시 생성만 수행한다.

## 메인 결정 (사용자 축자 아님)

- 행 2.19.5도 파견표에서 제거한다. 도출: 그 행의 완료 기준 중 R-01(원인 규명)·R-02(편집 귀속)는 첫 실행의 `행/2.d/19.d/5-보고.md`가 통과로 기록했고, 남은 기준이 R-03(전체 테스트 exit 0) 하나다. 확정 문면이 그 잣대를 행 2.19.6으로 일원화했으므로 2.19.5에는 수행할 실질이 없다.
- 행 2.19.2의 선행을 2.19.5에서 2.19.6으로, 행 2.19.z의 선행을 2.19.8.z에서 2.19.2로 재배선한다.
- 행 2.19.z의 판정 기준에서 전체 테스트 직접 판정·2.19.3 종료보고·기각 보관 재판정(S-08)을 제거한다. 기각 보관 항목은 판정 없이 보존한다. 완결 행 2.19의 CK-8 문면 중 이 결정이 제거한 판정은 이 결정이 대체한다.
- 행 2.19.6은 전제가 바뀌지 않으므로(전체 스위트 exit 0을 만드는 임무 그대로) 진행 중 실행을 중단하지 않는다.
