## 목적 진술

새 테스트 하네스의 실제 실행 계약과 활성 DAG의 생산·소비 계약이 일치하는지 검사한다. 완료 행은 역사 기록으로 보존한다. 제품 테스트는 실행하지 않는다.

## 불변식 목록

1. 일반 구현 행은 수정한 동작을 직접 검사하는 정확한 테스트 이름만 실행한다.
2. 같은 빌드 기록의 테스트 실행은 빌드를 반복하지 않는다.
3. 행 2.14만 최종 빌드, 데이터 검증, 전체 일반 테스트를 소유한다.
4. 전체 일반 테스트는 최종 빌드 기록의 `hidden: false` 이름 전건을 명시적 논리 조각으로 가진다.
5. 검증 행과 싱크는 기존 `result.json`과 해시를 판정한다. 같은 전체 테스트를 반복하지 않는다.
6. 테스트 실패와 프로세스 실패를 다른 처분으로 기록한다.
7. 승인 수리 뒤 파견표 검산이 exit 0이어야 한다.
