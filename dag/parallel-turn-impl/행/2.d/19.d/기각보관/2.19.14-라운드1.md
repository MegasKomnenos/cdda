## R1-03

제목: R1-2 — 선행 수리 범위가 새 overmap 종료 결함까지 확장된다

### 위치
`.sdd/dag/parallel-turn-impl/행/2.d/19.d/7.md` 9행의 T-08은 다른 난수 초기값 실패를 같은 행에서 규명하고 수리하게 한다. `.sdd/dag/parallel-turn-impl/행/2.d/19.d/13.md` 8~9행은 `overmap_terrain_coverage`의 메모리 접근 결함을 규명하고 `mapbuffer` 등 제품 파일을 수리하게 한다. 같은 파일 39행은 이 수리를 사용자 결정 「선행 수리」의 범위로 읽는다.

### 기준
`.sdd/dag/parallel-turn-impl/결정/상신-2.19.2-1.md` 31행은 사용자가 선택한 선행 수리의 임무를 다음 두 실패로 닫는다.

```
수리 행의 임무는 두 실패(`iteminfo_test.cpp:2783` · `crafting_test.cpp:1844`)의 원인 규명과 수리이고, 완료 기준은 전체 테스트 exit 0의 증거 실물이다.
```

`.claude/skills/do-dag/references/검증_체제.md` 185~186행은 코퍼스 밖 사실의 처분을 다음처럼 정한다.

```
코퍼스는 수리 근거의 상한이다. 코퍼스에는 지급물과 기준선의 원자료 목록이 든다.
코퍼스 밖 사실이 필요하면 검증런의 일반 발견·상신 경로를 쓴다.
```

### 영향
사용자는 두 제작 테스트 실패의 선행 수리를 선택했다. 행 2.19.13이 `overmap_terrain_coverage`와 `mapbuffer`의 제품 수리를 직접 수행하면, 사용자가 선택하지 않은 결함과 파일까지 수리 범위가 넓어진다. 반대로 수리를 중단하면 기준 실행의 전체 테스트 exit 0은 아직 충족하지 못한다.

### 상신
#### 읽은 범위

지급물 밖에서 `C:\cdda\.sdd\dag\parallel-turn-impl\결정\상신-2.19.2-1.md` 전건, `C:\cdda\.sdd\dag\parallel-turn-impl\행\2.d\19.md` 전건, `C:\cdda\.claude\skills\do-dag\references\배정.md` 「배정표」, `C:\cdda\.claude\skills\do-dag\계약\검증런.md` 「발견 처리」, `C:\cdda\.sdd\dag\parallel-turn-impl\행\2.d\19.d\13.md`가 가리키는 `overmap_terrain_coverage`와 `mapbuffer` 좌표를 열었다. 사용자 결정, 기준 실행 노드, 검증 체제는 확인했다. `overmap_terrain_coverage`와 `mapbuffer`의 제품 정의·원자료 전문은 이 범위에서 열지 않았다.

#### 세계 물음

기준 실행을 수행하는 작업자는 전체 테스트의 새 종료 결함을 발견했다. 작업자는 사용자 결정에 없는 `mapbuffer` 제품 수리를 직접 수행해도 되는가. 사용자 결정은 두 제작 테스트 실패만 명시한다.

#### 선택지

선택지 1은 행 2.19.13의 제품 수리를 승인한다. 기준 실행은 알려진 `overmap_terrain_coverage` 종료 결함을 수리한 뒤 전체 테스트 exit 0을 다시 확인할 수 있다. 수리 범위는 사용자 결정에 새로 적은 종료 결함과 그 원인 파일로 넓어진다.

선택지 2는 선행 수리를 두 제작 테스트 실패로 제한한다. 행 2.19.13은 제품 파일을 고치지 않고 예외 보고를 남긴다. 기준 실행은 전체 테스트 exit 0을 입증하지 못하므로 행 2.19.z와 행 2.6은 미완결로 남는다.

선택지 3은 `overmap_terrain_coverage`의 seed `1787724297` 재현, 최초 잘못된 메모리 접근, 그 원인 파일에 한정해 제품 수리를 승인한다. 이후 새 전체 테스트 실패는 별도 상신으로 보낸다. 기준 실행은 현재 확인한 결함을 수리할 수 있고, 수리 범위는 열린 일반 규칙으로 바뀌지 않는다.

#### 변형 물음

선택지 1의 열린 수리 범위는 선택지 3으로 줄일 수 있다. 선택지 3은 현재 종료 결함의 원인 파일만 승인하므로 뒤에 나타나는 다른 실패를 자동으로 수리하지 않는다.

#### 추천 하나

선택지 3을 추천한다. 이 선택지는 현재 전체 테스트를 막는 `overmap_terrain_coverage` 종료 결함을 처리하게 한다. 동시에 사용자 결정의 두 실패 한정을 이후의 다른 제품 수리까지 자동으로 넓히지 않는다.
