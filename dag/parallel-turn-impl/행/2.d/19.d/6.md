## 임무

1. 불변식 네 파일과 두 결정 파일을 읽는다.
2. 루트와 서브모듈의 현재 변경을 실측한다. 기존 변경을 되돌리지 않는다.
3. 세 테스트의 기존 실패 증거와 현재 소스를 대조한다. 실측 없이 원인을 확정하지 않는다.
4. 실패 원인을 수리한다. 병렬 턴 구현 파일은 편집하지 않는다.
5. 최종 소스 상태에서 `C:\cdda\build-tests.ps1`을 실행한다. stdout의 `BUILD_RECORD` 경로를 기록한다.
6. 빌드 기록의 세 테스트 이름이 일반 테스트로 등록됐는지 검사한다.
7. `C:\cdda\build\dag-parallel-turn-impl\2.19.6\<build_id>\`를 만든다. `run` 하위 디렉터리는 만들지 않는다.
8. `C:\cdda\test-harness\TestHarness.psm1`을 불러온다. 아래 입력 객체를 `ConvertTo-NormalizedManifest`로 정규화한다. 정규화한 객체를 `Write-JsonFile`로 `C:\cdda\build\dag-parallel-turn-impl\2.19.6\<build_id>\manifest.json`에 쓴다.

```json
{
  "schema_version": 1,
  "seed": 1787642233,
  "chunks": [
    {
      "id": "crafting",
      "tests": [
        "proficiency_gain_short_crafts",
        "crafting_skill_gain"
      ]
    },
    {
      "id": "monster",
      "tests": [
        "monster_speed_description"
      ]
    }
  ]
}
```

9. 새 실행에서는 아래 명령을 실행한다. `<build_id>`와 `<build.json>`은 5번의 빌드 기록에서 얻는다.

```powershell
.\run-tests.ps1 `
  -BuildRecord '<build.json>' `
  -RunDirectory 'C:\cdda\build\dag-parallel-turn-impl\2.19.6\<build_id>\run' `
  -Manifest 'C:\cdda\build\dag-parallel-turn-impl\2.19.6\<build_id>\manifest.json'
```

10. 실행이 완료되면 원본 `manifest.json`과 `run\input\manifest.json`의 SHA-256을 대조한다. 두 값은 같아야 한다. 같은 값을 `result.json`의 `manifest_sha256`과 대조한다.
11. 같은 소스와 빌드 기록의 실행만 아래 명령으로 다시 연다. 중단 실행은 미완료 논리 조각부터 재개한다. 완료 실행은 논리 조각을 다시 실행하지 않는다.

```powershell
.\run-tests.ps1 -Resume 'C:\cdda\build\dag-parallel-turn-impl\2.19.6\<build_id>\run'
```

12. 종료 코드 0은 세 테스트 통과다. 종료 코드 1은 완료된 테스트 실패다. 종료 코드 2는 명세 결함이다. 종료 코드 3은 하네스가 유효한 실행 상태를 확립하지 못한 오류다. 빌드 기록, 실행 파일, 소스, 검증 기록의 불일치, 따로 분류하지 않은 실행 오류, 정상 종료한 테스트 프로세스의 조각 결과 누락이 여기에 든다.
13. 종료 코드 1이면 `result.json`의 실패 테스트를 원인 좌표에 연결한다. 소스를 고친 뒤 새 빌드 기록과 새 실행 디렉터리로 5번부터 반복한다.
14. 종료 코드 2나 3이면 `run` 디렉터리, `run.json`, 원본 명세, `run\input\manifest.json`, 빌드 기록, 완료 조각 결과의 존재와 SHA-256을 검사해 보고한다. 기존 `run` 디렉터리는 바꾸지 않는다. `-Resume`을 실행하지 않는다. 원인을 수리한 뒤 5번부터 새 빌드 ID와 새 실행 디렉터리로 반복한다.
15. `result.json`이 S-09를 충족할 때 보고를 쓴다. 보고는 S-01부터 S-15까지의 증거를 지목한다.
