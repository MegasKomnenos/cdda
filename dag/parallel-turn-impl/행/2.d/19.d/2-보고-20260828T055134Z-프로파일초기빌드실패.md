기준 출력 경로와 전용 빌드 경로가 현재 존재한다. 두 경로를 보존한 채 이 실패 처분을 소비한다. `turn-profile.json`이 없으므로 seed, 완료 턴, 실행 파일 SHA-256은 후속 작업이 새 기준 실행으로 확인해야 한다.

## 반증 의무

행 2.19.6 보고의 테스트 통과를 기준 프로파일 통과로 읽으면 안 된다. 행 2.19.6의 세 표적 테스트는 통과했지만, 이번 프로파일은 결과 JSON을 만들지 못했다.

# 증거 부록

## 부록 1 — 행 2.19.6 JSON 대조

빌드 기록 `C:\cdda\build\test-builds\20260828T032447628Z-9992af2a88db\build.json`의 `build_id`는 `20260828T032447628Z-9992af2a88db`다. 결과 `C:\cdda\build\dag-parallel-turn-impl\2.19.6\20260828T032447628Z-9992af2a88db\run\result.json`의 `build_id`도 같은 값이다.

빌드 기록 SHA-256은 `3E445493E3CF33AB13A0214476B328BBF5E265DF20B81525886C633FA554CB88`이다. 결과의 `build_record_sha256`은 같은 64자리 값이다. 빌드 기록의 실행 파일 SHA-256과 결과 조각의 실행 파일 SHA-256은 `9992af2a88db44e170cdb0e6b00eaa4d087e434ef726bf05e3dbe0c086a953d1`이다.

명세 `C:\cdda\build\dag-parallel-turn-impl\2.19.6\20260828T032447628Z-9992af2a88db\manifest.json`의 테스트 이름은 `proficiency_gain_short_crafts`, `crafting_skill_gain`, `monster_speed_description`이다. 결과 조각의 테스트 이름 집합도 같은 세 이름이다. 두 조각과 세 테스트 결과는 모두 `execution_status: completed`, `outcome: passed`다.

## 부록 2 — 시작 상태

루트 시작 HEAD는 `c3fee776de5faf8769cd8ad6257669966dedbaa6`다. 서브모듈 시작 HEAD는 `3092abfcfcbd30c9d97bd12cafda07daab54178c`다. 두 값은 40자리 소문자 16진 커밋 객체 ID다.

시작 상태의 명령과 stdout은 `C:\cdda\build\turn-parallel-root-status.txt` 및 `C:\cdda\build\turn-parallel-submodule-status.txt`의 `시작 상태` 절에 있다. 각 파일은 `status --short --branch`, `rev-parse HEAD`, staged diff, unstaged diff, untracked 파일을 순서대로 기록한다.

## 부록 3 — 프로파일 시작 조건

시작 직전 `Test-Path -LiteralPath 'C:\cdda\cataclysm-dda\turn-profile-results\turn-parallel-baseline'`과 `Test-Path -LiteralPath 'C:\cdda\build\dag-parallel-turn-impl\2.19.2\profile-cmake'`은 모두 `False`였다.

실행 명령은 아래와 같다.

```powershell
pwsh -File 'C:\cdda\cataclysm-dda\tools\profile-turns.ps1' -Turns 10000 -Seed 'cdda-turn-profile-v1' -BuildDirectory 'C:\cdda\build\dag-parallel-turn-impl\2.19.2\profile-cmake' -OutputDirectory 'C:\cdda\cataclysm-dda\turn-profile-results\turn-parallel-baseline' -NoOpen
```

## 부록 4 — 프로파일 실패

명령은 전용 CMake 구성 뒤 `cataclysm-tiles.vcxproj`의 MSBuild 실행에서 종료했다. `profile-turns.ps1`의 `Invoke-Checked`는 종료 코드가 0이 아니면 `Command failed with exit code <코드>: <명령>` 오류를 던진다. 이 실행에서 원래 PowerShell 프로세스의 최종 종료 코드는 실행기가 반환하지 않아 회수하지 못했다.

`C:\cdda\build\dag-parallel-turn-impl\2.19.2\profile-cmake\`은 존재한다. `C:\cdda\cataclysm-dda\turn-profile-results\turn-parallel-baseline\`은 비어 있다. `turn-profile.json`과 RelWithDebInfo `cataclysm-tiles.exe`는 없다.

## 부록 5 — 실행 범위와 표면

이 행은 `profile-turns.ps1`만 실행했다. 제품 테스트와 data consistency는 실행하지 않았다. 이 행은 제품 소스, 새 원장, 새 공개 필드, 새 JSON 키, 새 노드 주입 인터페이스를 만들지 않았다.

## 부록 6 — 종료 상태

종료 상태의 명령과 stdout은 `C:\cdda\build\turn-parallel-root-status.txt` 및 `C:\cdda\build\turn-parallel-submodule-status.txt`의 `종료 상태` 절에 있다. 두 종료 HEAD는 각각 시작 HEAD와 같다. 두 저장소의 staged diff는 시작과 종료 모두 없다. 기존 변경은 유지했다. 이 행이 만든 상태 파일, 보고, 전용 빌드 경로, 빈 기준 출력 경로만 시작 상태에 없다.

## 부록 7 — 처분

반환 코드는 `프로파일실행실패`다. 기준 출력 경로와 전용 빌드 경로를 보존한다. 이 행은 두 경로를 삭제하거나 덮어쓰지 않는다.
