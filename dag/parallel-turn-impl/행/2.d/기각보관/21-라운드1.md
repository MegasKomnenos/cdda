```
        throw (New-HarnessException -ExitCode 3 -Message '소스 상태가 빌드 기록과 다릅니다. 새 빌드를 만드세요.')
    }
}
```

### 영향
작업자는 재개 입력 해시, 데이터 검증 기록, 완료 조각 결과가 어긋난 경우를 원인 조사 대상에서 빠뜨릴 수 있다. 작업자는 그 실행 디렉터리를 `-Resume`으로 다시 열거나, 같은 빌드 ID의 불일치 증거를 새 실행의 증거로 혼합할 수 있다. 그러면 중단 재개와 프로세스 실패를 분리한 사용자 결정 9~10항을 검증할 수 없다.
