# 병렬 프로파일 schema와 실행 폭 결선

- 목표: 작업자 평가 CPU, 직렬 병합 CPU, 주 스레드 CPU, 변경·충돌 계수와 실행 폭을 JSON·HTML·PowerShell에 같은 의미로 노출한다.
- 완료 기준: C-01. `schema_version`이 기존 값보다 크다. 모든 턴 JSON 레코드와 HTML 상세가 `primary_thread_cycles`를 소비한다. C-02. 공개 계측 API가 작업자별 전용 누적 저장소에 `worker.<측정 요소>`를 더한다. 주 스레드는 평가 파동 종료 뒤 작업자 전건을 합산한다. 작업자 스레드는 기존 열린 구간 스택을 공유하지 않는다. C-03. 공개 계측 API가 주 스레드 직렬 적용 CPU를 `reduce.<측정 요소>`로 기록한다. C-04. `background.other`는 프로세스 CPU에서 주 스레드 CPU와 작업자 CPU를 뺀 음수가 아닌 값이다. C-05. 턴 JSON이 변경 레코드 수와 같은 대상 충돌 수를 기록한다. C-06. metadata `turn_workers`는 주 스레드를 포함한 실제 평가 스레드 수다. 양수 요청은 같은 값이고 0 요청은 1 이상이다. C-07. `tools/profile-turns.ps1`은 `-TurnWorkers N`을 게임에 전달한다. 스크립트는 JSON `turn_workers`를 읽는다. 양수 요청과 JSON 값이 다르면 0이 아닌 종료 코드로 실패한다. C-08. Catch2 테스트 `turn profiler records parallel CPU and change counters`, `turn profiler renders raw data and all required HTML views`, `turn profiler accounts for background CPU cycles`가 각 이름으로 실재한다. 첫째 테스트는 C-02, C-03, C-05, C-06의 작업자·병합 CPU, 변경·충돌 계수, `turn_workers`를 검사한다. 둘째 테스트는 C-01의 schema_version과 `primary_thread_cycles` JSON·HTML 결선을 검사한다. 셋째 테스트는 C-04의 `background.other` 차감을 검사한다. 세 테스트를 논리 조각 `2.6.2-profiler-surface` 하나로 실행해 모두 통과한다.
