## 임무

1. 불변식 파일 전건을 먼저 읽는다.
2. 인계문 원문을 처음부터 끝까지 직접 읽는다. 인계문의 설명을 액면가로 믿지 않는다.
3. 인계문이 지목한 원자료와 코드 좌표를 저장소에서 직접 연다. 분해를 좌우하는 사실과 능력 상한을 실측한다.
4. 인계문 요구와 현재 저장소 상태의 차분을 원자 요구 단위로 측정한다.
5. `references/분해_원리.md` 1절을 적용해 작업 성격, 급소 사실, 구현 경계, 크리티컬 영역 후보를 분류한다.
6. `기준선.md`에 정본 목록과 차분, 원자료 목록과 확보 상태, 무효화 계통, 전역 규율 포인터를 적는다.
7. `기준선.md`에 비범위와 후속 처분, 확정·미결 분류, 재량 위임 조항, 런타임 환경, 생성 시점 HEAD를 적는다.
8. 미결은 차단과 비차단으로 가른다. 비차단 미결에는 fail-closed 기본값과 재평가 트리거를 적는다.
9. 체급 `전면`을 실물에 비추어 재검증한다. 체급 변경이 필요하면 게이트 1의 선택지로 올린다.
10. `결정/1-프레임체급.md`에 프레임, 체급, 구현 범위, 미결 사용자 결정을 브리핑한다.
