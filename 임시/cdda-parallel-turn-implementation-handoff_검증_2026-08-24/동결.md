## 목적 진술

이 산출물은 이전 대화를 볼 수 없는 새 Codex 세션이 현재 `C:\cdda` 저장소에서 자동 세계 갱신의 CPU 병렬화를 구현하도록 지시한다. 산출물은 실제 코드·프로파일 자료·Git 상태와 일치해야 한다. 설계의 상태 경계, 소유권, 변경 순서, 난수, 스레드 수명, 검증 기준은 서로 모순 없이 구현 가능해야 한다. 산출물만 읽은 세션이 기존 사용자 변경을 보존하고, 실패 조건을 판정하고, 완료 여부를 입증할 수 있어야 한다.

## 불변식 목록

- 결론: 첫 완료 범위는 CPU 작업자 스레드를 사용한다. GPU는 CPU 구현을 측정한 뒤 조밀 격자 계산의 병목이 남을 때만 검토한다.
- 필수 의미: 자동 세계 갱신의 병렬 계산은 플레이어 행동 뒤 고정한 같은 입력 상태를 읽는다. 계산 결과는 계산이 끝난 뒤 결정적인 순서로 적용한다.
- 필수 결정성: 같은 시작 상태와 난수 초기값은 작업자 수와 실행 순서에 무관하게 같은 끝 상태를 만든다.
- 필수 범위: 문서가 첫 완료 범위로 닫은 측정 요소와 직렬 유지 대상으로 닫은 측정 요소를 구별한다. 범위 변경에는 코드·프로파일 근거가 필요하다.
- 필수 안전: 기존 사용자 변경을 삭제하거나 되돌리지 않는다. 작업자 스레드는 공유 가변 상태, 전역 난수 엔진, 오디오 라이브러리를 직접 사용하지 않는다.
- 필수 논거: 상태 고정 시점, 평가와 적용의 분리, 작업 소유 대상, 충돌 순서, 난수 키, 작업자 수명, 기능·성능 게이트를 구현 절차와 완료 조건까지 일관되게 연결한다.
- 필수 전거: 기준 원문 절에 적은 실제 파일과 Git·프로파일 실측이다. 산출물의 자기 기술은 전거가 아니다.
- 현재성: 현재 저장소와 달라질 수 있는 커밋·브랜치·작업 트리·경로·명령은 실측과 일치하거나 재확인 절차로 바꾼다.
- 불확실성: 실제 코드에서 확인하지 못한 구조·성능·구현 가능성은 확정 사실처럼 쓰지 않는다. 확인 명령과 실패 시 처리를 적는다.
- 독립성: 이전 대화와 작성 경위를 모르는 독자가 용어, 전제, 작업 순서, 검증 증거, 반환 형식을 이해할 수 있어야 한다.
- 분량 상한: 없음.
